# hktggame · HK 通关游戏

🎮 **在线直接玩：<https://hiingai.github.io/hktggame/>**

单文件 HTML5 平台跳跃游戏，零依赖、零构建、无 CDN。打开网页即玩，手机也支持。

## 玩法

收集关卡里**所有钥匙** → 走进发光的门 → 通关。共 3 关：

| 关卡 | 主题 | 特点 |
|---|---|---|
| 第一关 | 起步 | 熟悉手感，3 把钥匙 |
| 第二关 | 断桥 | 地面有断口，4 把钥匙，尖刺预警 |
| 第三关 | 尖刺 | 高台连跳，5 把钥匙，3 处尖刺 |

## 操作

| 动作 | 键盘 | 触屏 |
|---|---|---|
| 移动 | `←` `→` 或 `A` `D` | 左下 ◀ ▶ |
| 跳跃 | `空格` / `↑` / `W` | 右下 ⤒ |
| 重开本关 | `R` | — |
| 静音 | `M` | — |

跳跃是**可变高度**的：轻点跳得低，按住跳得高。同时带 coyote time（离地后 0.09s 内仍可起跳）和跳跃输入缓冲，手感更宽容。

## 文件

- `hktggame.html` — 游戏本体，全部逻辑与美术都在里面（约 23KB）
- `index.html` — 根路径跳转页，让 `https://hiingai.github.io/hktggame/` 直接可用

想离线玩？下载 `hktggame.html` 双击即可，不需要服务器。

## 技术

- 纯 Canvas 2D + requestAnimationFrame
- 逐轴 AABB 碰撞，重力/摩擦/加速度全部手写
- 音效用 WebAudio 实时合成（正弦/方波/锯齿），不加载任何音频文件
- 最佳通关时间存 localStorage
